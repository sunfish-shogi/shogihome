# 局面図の出力

現在の局面を画像 (PNG または JPEG) として出力する機能を提供する。

## スタイル

| スタイル | 説明                                                             |
| :------- | :--------------------------------------------------------------- |
| 書籍風   | 白背景に文字で盤面を表現する。見出し・コメントも一緒に出力する。 |
| 対局風   | メイン画面と同じ盤面画像・駒画像を使って出力する。               |

書籍風の場合のみ、書体・文字サイズ・文字の太さ・持ち駒のラベル・見出しを設定できる。

## 見出し

書籍風のスタイルで盤面の上部に表示する文字列。
形式をプルダウンから選択する。

先頭の `無し` を選択した場合は見出しを出力しない。
それ以外の項目名には、その形式を選んだ場合に現在の局面で実際に出力される文字列を表示する。
例えば 35 手目 (最終手が☗７六歩) の局面で見出しのテキストに `第1図` を入力している場合は次のようになる。

| プルダウンの項目           | 形式                                    |
| :------------------------- | :-------------------------------------- |
| `無し`                     | 見出し無し                              |
| `35手目 ☗７六歩まで`       | 手数と最終手                            |
| `第1図`                    | しおり・入力テキスト                    |
| `☗７六歩まで`              | 最終手のみ                              |
| `第1図 は ☗７六歩まで`     | しおり・入力テキストと最終手            |
| `【35手目 ☗７六歩まで】`   | 手数と最終手 (括弧付き)                 |
| `【第1図】`                | しおり・入力テキスト (括弧付き)         |
| `【☗７六歩まで】`          | 最終手のみ (括弧付き)                   |
| `【第1図 は ☗７六歩まで】` | しおり・入力テキストと最終手 (括弧付き) |

しおりも入力テキストも空の場合は、項目名に限りその部分を `<自由入力>` で埋める。
(`<自由入力>`、`<自由入力> は ☗７六歩まで` のように表示する。)

最終手が無い局面 (初期局面や、分岐の都合で直前の指し手が存在しない局面) では、
`☗７六歩まで` に相当する部分を手番に応じて `先手番` または `後手番` に置き換える。
このとき手数の部分は出力しない。

### しおり・入力テキスト

「しおり・入力テキスト」を含む形式では、その部分の文字列を次の優先順位で決定する。

1. 現在の局面にしおりが設定されている場合はしおりの名前
2. ダイアログの入力欄に入力したテキスト

どちらも空の場合は次のように扱う。

- 「しおり・入力テキスト」の形式では「手数と最終手」の形式で出力する。
- 「しおり・入力テキストと最終手」の形式では「最終手のみ」の形式で出力する。

入力欄は「しおり・入力テキスト」を含む形式を選択している場合のみ有効になる。

## 設定の保存

ダイアログで変更した設定はアプリ設定として保存する。

見出しの形式を持たない旧バージョンの設定を読み込んだ場合は、次のように変換する。

- 「しおりを見出しに使う」が有効、または見出しのテキストが空でない場合は「しおり・入力テキスト」
- それ以外の場合は「手数と最終手」
