# 局面図の出力

現在の局面を画像 (PNG または JPEG) として出力する機能を提供する。

## スタイル

| スタイル | 説明                                                             |
| :------- | :--------------------------------------------------------------- |
| 書籍風   | 白背景に文字で盤面を表現する。見出し・コメントも一緒に出力する。 |
| 対局風   | メイン画面と同じ盤面画像・駒画像を使って出力する。               |

書籍風の場合のみ、書体・文字サイズ・文字の太さ・持ち駒のラベル・見出しを設定できる。

## 見出し

書籍風のスタイルで盤面の上部に表示する文字列。
形式をプルダウンから選択する。

先頭の `無し` を選択した場合は見出しを出力しない。
それ以外の項目名には、その形式を選んだ場合に現在の局面で実際に出力される文字列を表示する。
項目は比較的短い形式が先に並び、括弧付きの形式は後ろにまとめる。

例えば 35 手目 (最終手が☗７六歩) の局面で、しおりに `第1図`、
自由入力のテキストに `テーマ図` を設定している場合は次のようになる。

| プルダウンの項目              | 形式                        |
| :---------------------------- | :-------------------------- |
| `無し`                        | 見出し無し                  |
| `第1図`                       | しおり                      |
| `テーマ図`                    | 自由入力                    |
| `☗７六歩まで`                 | 最終手                      |
| `35手目 ☗７六歩まで`          | 手数と最終手                |
| `第1図 は ☗７六歩まで`        | しおりと最終手              |
| `テーマ図 は ☗７六歩まで`     | 自由入力と最終手            |
| `【第1図】`                   | しおり (括弧付き)           |
| `【テーマ図】`                | 自由入力 (括弧付き)         |
| `【☗７六歩まで】`             | 最終手 (括弧付き)           |
| `【35手目 ☗７六歩まで】`      | 手数と最終手 (括弧付き)     |
| `【第1図 は ☗７六歩まで】`    | しおりと最終手 (括弧付き)   |
| `【テーマ図 は ☗７六歩まで】` | 自由入力と最終手 (括弧付き) |

最終手が無い局面 (初期局面や、分岐の都合で直前の指し手が存在しない局面) では、
`☗７六歩まで` に相当する部分を手番に応じて `先手番` または `後手番` に置き換える。
このとき手数の部分は出力しない。

その結果として「手数と最終手」と「最終手」のように複数の形式が同じ文字列になる場合は、
プルダウンに重複して表示せず 1 つだけ表示する。
(選択している形式が消えないように、その形式を優先して残す。)

### しおりと自由入力

しおりを使う形式と自由入力のテキストを使う形式は独立しており、互いに代替しない。

しおりを使う形式は、現在の局面にしおりが設定されていない場合はプルダウンに表示しない。
ただし、すでに選択している形式は表示したままにする。
(しおりのある局面で選択した後に、しおりのない局面へ移動した場合。)

自由入力のテキストの入力欄は、自由入力を使う形式を選択している場合のみ有効になる。

使用するテキストが空の場合は次のように扱う。

- テキストのみの形式では見出しを出力しない。
- 最終手と組み合わせる形式では最終手のみを出力する。

プルダウンの項目名に限り、テキストが空の場合はその部分を
`<しおり>` または `<自由入力>` で埋める。

## 設定の保存

ダイアログで変更した設定はアプリ設定として保存する。

見出しの形式を持たない旧バージョンの設定を読み込んだ場合は、次のように変換する。

- 「しおりを見出しに使う」が有効の場合は「しおり」
- 見出しのテキストが空でない場合は「自由入力」
- それ以外の場合は「手数と最終手」
