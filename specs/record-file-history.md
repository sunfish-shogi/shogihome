# 棋譜ファイル履歴

「ファイル」メニューの「履歴」ダイアログで表示される、棋譜ファイルの履歴と自動バックアップの仕様。
Electron 版のみの機能で、Web 版では履歴は常に空になる。

## 保存先

`<userData>/record_file_history.json` に、1 つの配列 `entries` として古い順に保存する。

エントリの種類は次の通り。

| class      | 内容                                                            |
| ---------- | --------------------------------------------------------------- |
| `user`     | ユーザーが開いた/保存したファイルのパス                         |
| `backupV2` | 自動バックアップ（v1.21.0 以降）。KIF 形式の棋譜本文を直接保持  |
| `backup`   | 自動バックアップ（v1.20.x 以前）。`backup/kifu/` 以下のファイル |

## 保持数

ユーザーファイルとバックアップは別々に上限を持つ。

- `user`: 最大 100 件
- `backupV2` と `backup` の合計: 最大 20 件

エントリを追加するたびに、種類ごとに新しい方から数えて上限を超えた古いエントリを削除する。
`backup` エントリを削除する際は対応するバックアップファイルも削除する。

同じパスの `user` エントリを追加した場合は、既存のエントリを削除して末尾に追加する。

## フィルタ

ダイアログ上部の入力欄に検索ワードを入力すると、インクリメンタルに一覧を絞り込む。

- 検索ワードは空白で区切ると AND 条件になる。
- 大文字と小文字は区別しない。
- 照合対象は次の通り。
  - `user`: フルパスと、ファイルの内容（生テキスト全体。コメントやしおりも含む）
  - `backupV2`: 保持している KIF の生テキスト全体
  - `backup`: 検索対象外（検索ワードが入力されている間は表示しない）
- ユーザーファイルの内容は、検索ワードが初めて入力された時点でまとめて読み込み、ダイアログを閉じるまで保持する。
  - 文字コードは拡張子ごとの既定値（`.kif`/`.ki2` は Shift_JIS、それ以外は UTF-8）で読み込む。
    アプリ設定の文字コード判定が自動判定の場合は自動判定する。
  - 対応する棋譜形式の拡張子でないファイル、存在しないファイル、10MB を超えるファイルは内容を照合せず、パスのみ照合する。
  - 読み込み中はパスのみで照合し、読み込み完了後に内容での照合結果を反映する。

## ボタン

- `user`: 「フォルダを開く」（ファイルを含むフォルダを OS のファイルマネージャーで開く）、「開く」
- `backupV2` / `backup`: 「復元」
