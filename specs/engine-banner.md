# エンジンのバナー画像

エンジン選択の一覧 (PlayerSelector) で、項目の背景にエンジンごとのバナー画像を表示する。

## 画像の探し方

### WebAssembly エンジン

マニフェスト (`engine.json`) の `banner` で指定した画像を使う ([wasm-engine-abi.md](wasm-engine-abi.md) を参照)。
ディレクトリの探索はしない。

### それ以外のエンジン (デスクトップ版)

次のディレクトリを上から順に調べ、`banner.*` が見つかったものを **全て** その順で横に並べる。

1. エンジンの実行ファイルと同じディレクトリ
2. エンジンオプション `EvalDir` が示すディレクトリ
3. エンジンオプション `BookDir` が示すディレクトリ

- ファイル名は `banner` に拡張子 `.png`・`.jpg`・`.jpeg`・`.gif`・`.webp` のいずれかを付けたもの。
  大文字・小文字は区別しない
- 1 つのディレクトリに複数ある場合は、上記の拡張子の順で 1 つだけ使う
- オプションの値は保存された現在値 (未設定なら既定値) を使う。空文字列ならそのディレクトリは調べない
- 相対パスはエンジンの実行ファイルのディレクトリを起点に解決する
  (エンジンはこのディレクトリを作業ディレクトリにして起動するため、エンジンから見た場所と一致する)
- 解決したディレクトリが前のものと同じ場合は重複して並べない。大文字・小文字の違い (Windows) や
  シンボリックリンクを経由した場合も同じとみなせるよう、実体のパスで比べる
- ディレクトリが存在しない・読めない場合は無視する

## 反映のタイミング

バナー画像の情報 (`USIEngine.banners`) は保存された値を使わず、エンジンの一覧を読み込むたびに作り直す。
各ダイアログは開くたびに一覧を読み込むため、エンジンを登録した後で画像を置いたり差し替えたりした場合も、
次にダイアログを開いたときに反映される。

- 画像を差し替えたときにキャッシュされた古い画像が表示されないよう、URL には更新日時をクエリとして付ける
- エンジン設定の画面で `EvalDir`・`BookDir` を変更した場合は、ダイアログを開き直すまで反映されない

## データ

`USIEngine.banners` は `{ url, source }` の配列で、表示する順に並ぶ。

| `source`   | 画像の場所                                       |
| ---------- | ------------------------------------------------ |
| `manifest` | WebAssembly エンジンのマニフェストで指定したもの |
| `engine`   | エンジンの実行ファイルと同じディレクトリ         |
| `EvalDir`  | エンジンオプション `EvalDir` が示すディレクトリ  |
| `BookDir`  | エンジンオプション `BookDir` が示すディレクトリ  |

`url` は `file:` URL で、表示するときに `user-file:` スキームに変換する。

## 表示

- 画像は項目の縦幅に合わせて拡大・縮小し、横幅はアスペクト比に従う
- 複数の画像は左から順に隙間なく並べ、項目の幅に収まらない部分は切り落とす
- 右側の空間は、最後の画像の右端を左右反転して引き伸ばし、ぼかしたもので塗る
- バナー画像が無いエンジンは ShogiHome 既定の画像を表示する
- 情報ボタンのメッセージダイアログには、マニフェストで指定した画像 (`source` が `manifest`) だけを表示する
